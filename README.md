# Prime Sphere Live

Public, results-only dashboard for the Prime Sphere Lock teaching range.

**Live page:** https://goddrivenbullet.github.io/prime-sphere-live/

This repository publishes the scoreboard, alerts, and a commit feed. It does
not contain the range's source code, keys, or secrets. The source remains in
a private repository.

The lock is an unaudited classroom-grade design. Do not use it for real secrets.
